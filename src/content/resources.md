## 核心组件

Vite+ 由以下开源项目构成：

| 工具                                                    | 用途                    |
| ------------------------------------------------------- | ----------------------- |
| [Vite](https://vite.dev/)                               | 开发服务器与前端构建    |
| [Rolldown](https://rolldown.rs/)                        | 基于 Rust 的应用打包    |
| [Vitest](https://vitest.dev/)                           | 测试运行器              |
| [Oxlint](https://oxc.rs/docs/guide/usage/linter.html)   | 代码检查（Oxc）         |
| [Oxfmt](https://oxc.rs/docs/guide/usage/formatter.html) | 代码格式化（Oxc）       |
| [tsdown](https://tsdown.dev/)                           | 库构建 / 独立可执行文件 |
| [Vite Task](https://github.com/voidzero-dev/vite-task)  | 任务编排                |
