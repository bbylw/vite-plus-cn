# 任务缓存

`vp run` 会缓存任务执行结果，让干净检出、CI 与日常开发都能复用已计算的产物，从而显著减少重复工作。

## 管理缓存

```bash
vp cache          # 查看缓存使用情况
vp cache clean    # 清理所有缓存
```

## 强制缓存开关

`vp run` 默认按需启用缓存。你可以显式控制：

```bash
vp run build --cache       # 强制开启缓存
vp run build --no-cache    # 强制关闭缓存
```

## 缓存的工作原理

Vite Task 根据任务输入（源文件、环境变量、依赖图等）计算缓存键。当相同的输入再次出现时，直接返回缓存结果，跳过实际执行。因此，批量运行同一组任务时，速度可得到极大提升。

结合 [`vp run`](/guide/run) 的依赖感知调度，缓存让 monorepo 的批量测试与构建更贴近“只执行一次”。
